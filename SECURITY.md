# Security Policy

Report security issues privately through GitHub Security Advisories for the
repository. Do not include secrets, private source code, or exploit details in
public issues.

Zimster is an instruction and adapter package. It does not require network
access, credentials, telemetry, or a hosted service. Harnesses and tools used
by an agent retain their own security boundaries and permission models.

Reports should include the Zimster and harness versions, configuration scope,
reproduction, and impact. Never attach credentials or private source. Generated
override collision, symlink, path traversal, unsafe archive, and configuration
precedence defects are security-relevant even without a network service.
